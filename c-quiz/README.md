# C언어 문제은행 — 정보과학 학습 웹앱

**접속:** https://informin.github.io/webapps/c-quiz/

업로드된 6쪽짜리 「정보과학 C언어 프린트」를 바탕으로 작성한 **100문항** 학습용 문제은행입니다. PDF 원본은 공개 저장소에 포함하지 않았습니다.

| 문항 유형 | 문항 수 |
|---|---:|
| 단답형 | 20 |
| 프로그램 실행 결과 분석 | 30 |
| 코드 빈칸/괄호 넣기 | 25 |
| 오류 찾기와 수정 | 15 |
| 프로그램 응용 | 10 |
| **합계** | **100** |

## 포함 범위

- 1쪽: 프로그램, 변수, 자료형, 변수명, 연산자, printf
- 2쪽: 기본 구조, 관계·논리 연산자, 복합 대입, 형 변환, 제어문자
- 3쪽: scanf, 정수·실수·문자·문자열 입력, 계산 프로그램
- 4쪽: if/else, 다중 조건, switch/case/default
- 5쪽: while, do~while, for, 중첩 반복문을 위한 준비
- 6쪽: 중첩 for, 합계 프로그램, 배열과 첨자

교재 중 현대 C언어 기준으로 보안 문제가 있는 `gets()` 예제는 출제에서 제외하였습니다. 이 교재에 나타나는 2026년 나이 계산 예제는 해당 연도의 학습 예제로만 사용합니다.

## 사용 방법

1. 유형/범위/문항 수를 선택합니다.
2. 답안을 입력하거나 오류 수정 보기를 선택합니다.
3. **채점 및 해설**로 정답과 해설을 확인합니다.
4. 문제를 넘겨 학습하고, 마지막에 전체 결과를 봅니다.
5. 오답 다시 풀기를 선택할 수 있습니다.

## 기술과 개인정보

- 정적 파일: `index.html`, `questions.js`, `app.js`
- 브라우저 내 결정적 채점: 별도 외부 API 호출이 없습니다.
- 학습 기록은 사용자 기기의 `localStorage`에만 저장됩니다.
- 개인정보 수집, 회원가입, 서버 저장, Gemini API 키 사용이 없습니다.
- 정답은 공개 JavaScript 파일에 포함됩니다. **시험 보안 목적이 아닌 연습용**입니다.
- 코드 실행을 평가하는 서비스가 아니며, 코드 출력값과 문법 등을 기준으로 정답과 해설을 제공합니다.
- 작성형 답안 채점은 제공된 정답과 허용된 대안 문자열을 기준으로 합니다. 의미가 같은 다른 코드가 오답 처리될 수 있습니다.

## 유지보수

- 문제 수정: `questions.js`의 JSON 객체
- 화면 스타일: `index.html`
- 채점 및 학습 기록: `app.js`
- GitHub Pages: 기존 `webapps` 저장소의 `main /(root)` 설정 그대로 자동 배포
